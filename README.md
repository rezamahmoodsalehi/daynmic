# جزیره پویا (Dynamic Island for Android)

Android 11+ (minSdk 30). Kotlin, View-based overlay, Material 3 + Material You.

## ساخت APK
**راه ۱ - GitHub Actions (بدون نصب چیزی):** پروژه را در یک ریپوی GitHub بگذارید و push کنید.
Actions → Build APK → Artifacts → `DynamicIsland-debug-apk`.

**راه ۲ - Android Studio:** پوشه را باز کنید، Build ▸ Build APK(s).
خروجی: `app/build/outputs/apk/debug/app-debug.apk`

## بعد از نصب
1. «نمایش روی سایر برنامه‌ها» را فعال کنید.
2. «دسترسی به اعلان‌ها» را فعال کنید (برای پیام‌ها و موسیقی برنامه‌های دیگر).
3. سوییچ «فعال بودن جزیره» را بزنید و از بخش تست امتحان کنید.
